VRAM RipperDoc - Performance Optimizer
======================================

Double-click the numbered files in order:

  1 - Scan my mods.bat
      Checks every texture and mesh mod you have installed and opens a report
      in your browser. The heaviest mods are at the top. Changes nothing.
      Big mod lists can take a few minutes; a progress counter shows how far it is.
      Using Mod Organizer 2? If no mods are found it asks for your MO2 folder once.
      Run through MO2, step 2 saves the fix as an MO2 mod named
      "VRAM RipperDoc Budget Fix": press F5 in MO2 and tick it to enable it.

  2 - Apply budget fix.bat   (optional)
      If the report says you are over budget, this adds ONE extra file with
      half-size copies of only the heaviest textures. Your mods are not changed.
      It scans first, then shows how many textures it would shrink, how big the
      file will be and roughly how long it takes, and asks before writing.
      A second question covers 4K textures of new clothing, cars and props
      (they only use VRAM while you use them). A progress counter shows how far
      it is; when it is done it shows the new file in Explorer.

  3 - Measure VRAM in game.bat   (optional)
      Records how much video memory the game really uses while you play.
      Run it once named "before", apply the fix, then again named "after"
      in the same save to see the difference.

  Undo budget fix.bat
      Removes the extra file from step 2. Everything is back as it was.

Reports are saved next to these files (VRAM-RipperDoc-Report.html).
Advanced options: open a terminal here and run  VramRipperdoc.exe --help
More info: README.md, or https://www.nexusmods.com/cyberpunk2077/mods/36878
